# ESP32 Arduino Sketches

Working sketches for ESP32-based hardware projects.

## Sketches

### pihole_dashboard_v2
Pi-hole stats dashboard. Copy `secrets.h` from the template and fill in your credentials.

### cyd_bt_speaker_spectrum_v2
Bluetooth speaker with FFT spectrum visualizer for the AITRIP CYD (ESP32-2432S028R).

### cyd_ticker
Stock ticker (AAPL / NVDA / TSLA) with live Finnhub data, no-flicker display.
Built for the AITRIP ESP32 CYD (ILI9341, 320×240).

### crowpanel_wifi_dashboard
WiFi dashboard for the Elecrow CrowPanel 7" ESP32-S3 HMI (800×480, LovyanGFX).
